HOW IT WORKS

Explicit semantics. Deterministic execution.

01 / WHEN

A trigger fires the routine. Time windows, boot, battery level, screen state, notifications, calls, SMS, connectivity, app opens, geofences, flip-to-glyph.

→

02 / ONLY IF

Conditions gate execution. Twelve-plus types compose with AND logic. A routine only acts when every condition holds.

→

03 / THEN

Actions run in order. Thirty-seven-plus action types, from toggles and notifications to Glyph patterns and Shizuku-backed system changes.

FEATURES

Built for control, not for show.

MODES

Persistent state, automatic restore

Sleep, Work, Gaming. A mode holds a set of toggles and reverts every one of them when it ends. No leftover state, no surprises.

GLYPH

Nothing Glyph integration

Drive light stripe zones A–E, the Glyph Matrix, and Glyph Toys from any routine. Patterns, countdowns, breathing effects.

SHIZUKU

Optional system-level toggles

Airplane mode, hotspot, NFC and more via Shizuku. Without it, the app degrades gracefully — every other path still works.

CAPABILITY

Asks the device, never guesses

Capability detection probes what the hardware and OS actually support. Routines expose only what works on this phone, today.

PORTABILITY

Import, export, share

Automations are JSON. Export a routine, send it to a friend, drop it back in. A template catalog ships in-app for common flows.

ENGINE

Priority and cooldown

Deterministic conflict resolution. Higher-priority routines win. Cooldowns prevent flapping. Behaviour is repeatable, not racy.

GLYPH
