HOW IT WORKS

Explicit semantics. Deterministic execution.

01 / WHEN

A trigger fires the mode. Time windows, boot, battery level, screen state, notifications, calls, SMS, connectivity, app opens, geofences, flip-to-glyph.

→

02 / ONLY IF

Conditions gate execution. Twelve-plus types compose with AND logic. A mode only acts when every condition holds.

→

03 / THEN

Actions run in order. Thirty-seven-plus action types, from toggles and notifications to Glyph patterns and Shizuku-backed system changes.

FEATURES

Built for control, not for show.

MODES

N° 01

Persistent state, automatic restore

Sleep, Work, Gaming. A mode holds a set of toggles and reverts every one of them when it ends. No leftover state, no surprises.

GLYPH

N° 02

Nothing Glyph integration

Drive light stripe zones A–E, the Glyph Matrix, and Glyph Toys from any mode. Patterns, countdowns, breathing effects.

SHIZUKU

N° 03

Optional system-level toggles

Airplane mode, hotspot, NFC and more via Shizuku. Without it, the app degrades gracefully — every other path still works.

CAPABILITY

N° 04

Asks the device, never guesses

Capability detection probes what the hardware and OS actually support. Modes expose only what works on this phone, today.

PORTABILITY

N° 05

Import, export, share

Automations are JSON. Export a mode, send it to a friend, drop it back in. A template catalog ships in-app for common flows.

ENGINE

N° 06

Priority and cooldown

Deterministic conflict resolution. Higher-priority modes win. Cooldowns prevent flapping. Behaviour is repeatable, not racy.

GLYPH

Light as a first-class output.

Nothing phones expose their LED hardware to apps. Nothing Modes treats that surface like any other actuator — addressable from modes, scriptable from the builder.

STRIPE ZONES A–E
Independent brightness control over each segment of the rear light strip.
GLYPH MATRIX
25×25 on Phone 3, 13×13 on Phone 4a Pro. Per-dot addressing for patterns, glyphs and animations.
GLYPH TOYS
Nothing Modes ships its own toy — text, marquee, progress rings, battery arc, icons — rendered on the matrix itself.

Fair warning: Nothing reserves the lights for one selected toy at a time. Glyph actions are visible while Nothing Modes is picked as the Glyph Toy (or Always-on toy) — the app links straight to that picker and shows who owns the matrix. Other apps' toys can't be triggered by us; that's a platform rule, not a missing feature.
