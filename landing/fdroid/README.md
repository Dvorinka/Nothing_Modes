# F-Droid self-hosted repository

This directory contains a self-hosted F-Droid repository for Nothing Modes.
It is served as part of the landing site, typically at `https://nothing-modes.vercel.app/fdroid/`.

## Why self-hosted?

Official F-Droid rejects the build because of:

- `com.google.android.gms:play-services-location` (geofence triggers)
- `nothing-integrations/libs/glyph-matrix-sdk-2.0.jar` (Nothing Glyph SDK)

A self-hosted repo keeps every feature while still offering F-Droid client updates.

## Add the repository

1. Install the F-Droid client.
2. Go to **Settings → Repositories → +**.
3. Enter: `https://nothing-modes.vercel.app/fdroid/`
4. Search for "Nothing Modes" and install.

## Important: one signature rule

APK signatures must stay identical across updates. If you installed a debug build first, uninstall it before installing the release build from this repo. Debug and release use different signatures and F-Droid updates will fail.

## Publishing a release

Run the release script after a GitHub release is published:

```bash
scripts/fdroid-release.sh <versionName> <versionCode>
```

This regenerates the F-Droid index from the GitHub release APK and commits the updated index files. Vercel then redeploys the landing site with the new index.

## Layout

- `config.yml` — F-Droid repo configuration.
- `metadata/com.tdvorak.nothingmodes.yml` — app metadata.
- `index-v2.json`, `index.jar`, `entry.json` — generated by `fdroid update`.
- `scripts/fdroid-release.sh` — release helper.
