Architecture

Multi-module Android stack

  • app — Hilt Application, manifest, widget, tile service.
  • ui — Jetpack Compose screens, theme, catalogs.
  • engine-core — automation model, conditions, actions, evaluator.
  • capabilities — Android state readers, action executor, permission logic.
  • automation-android — service, scheduler, receivers, boot lifecycle.
  • data — Room persistence, execution journal, store.
  • core-shizuku / device-tools / nothing-integrations — Shizuku, Nothing Glyph SDK, system integrations.
